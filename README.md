# Mechanist_data

## Directory Structure

```text
Mechanist_data/
|-- case/
|   |-- Mechanist-DNA/
|   |-- subliminal_learning/
|   |   |-- subliminal_learning_fruit/
|   |   `-- subliminal_learning_labsafety/
|   `-- belief/
|-- hypothesis/
|   |-- diversity_eval/
|   |-- quality_eval/
|   `-- hypothesis_library/
`-- reproduction/
```

- `case/` contains three Mechanist use cases
- `hypothesis/` contains hypothesis-generation and evaluation resources. `hypothesis_library/` provides the top 10 hypotheses generated by Mechanist in each of four domains: knowledge, safety, science, and language. `quality_eval/` evaluates hypotheses generated by Mechanist and the baselines in terms of novelty, impact, and testability. `diversity_eval/` contains an ablation study assessing how the scientific knowledge graph affects hypothesis diversity.
- `reproduction/` contains reproductions of multiple papers on mechanistic interpretability using Mechanist and baseline methods, together with the evaluation criteria and results from both human and LLM judges.
