## Check A — Ground-Truth Provenance

**Status: PASS**

HaluEval-General and ToxicChat labels are from the original benchmark datasets (`/data/zhenqian/data/monitoring/{hegen,toxicchat}/data.jsonl`), not generated by any model being evaluated. Labels are binary (0/1) and were part of the dataset's original annotation. This is genuine dataset GT.

**Task.md probe: "(i) probes/RFM fit on train, evaluated on test — no leakage?"**

Verification: The `c5_monitoring.py` code uses a clean 60/20/20 train/val/test split with a fixed seed=42. Probes are fit ONLY on `tr_acts[:n_tr]` (train split activations). Val split `va_acts[n_tr:n_tr+n_va]` is used for block selection. Test split `te_acts[n_tr+n_va:]` is used for the reported AUROC. The `split_data` function shuffles with a fixed seed before splitting. No data from val or test is used in probe/RFM fitting. **No leakage detected.**

Additionally, the split files are saved to disk (`halueval_{train,val,test}.jsonl`, `toxicchat_{train,val,test}.jsonl`), enabling reproducibility verification.

**Task.md probe: "(iv) ToxicChat balanced=584 (from 292 pos) — is the reported AUROC on the same balanced set as GPT-4o's? Fair comparison?"**

Verification: `c5_baselines.py` explicitly loads `c5_monitoring_test.jsonl` from the C5_monitoring run directory (`c5_dir / f"{bench_name}_test.jsonl"`), ensuring that GPT-4o is evaluated on exactly the same 118 test rows as the internal probe. The ToxicChat test set has pos=54, neg=64 (near-balanced). The comparison is fair.

## Check B — Score Normalization

**Status: PASS**

AUROC is a rank-based metric — it is invariant to monotone transforms of the score (scale-free). No normalization by model maximum is needed or applied. The probe_auroc function in rfm_core.py uses the rank-sum formula (verified in code) correctly. AUROC cannot be inflated by score normalization.

## Check E — Scope (claim-scoped)

**Status: PASS**

**Task.md probe: "(ii) GPT-4o judge prompt — is it fair (e.g., is it seeing the same evidence as the internal probe, or being deliberately handicapped)?"**

The GPT-4o judge (in `c5_baselines.py`) receives:
- For hallucination: the full (prompt, response) pair with a 5-point rubric ("Rate how likely the given RESPONSE contains a hallucination or fabricated claim").
- For toxicity: the full (prompt, response) pair with a 5-point rubric.

The internal probe sees: last-token activations of the (prompt, response) pair passed through Llama-3.1-8B-Instruct (formatted as `"USER: {prompt}\nASSISTANT: {response}"`).

The evidence available to GPT-4o (text content of both prompt and response) is strictly richer than what the internal probe sees (last-token hidden state). The GPT-4o judge is NOT handicapped — it has full textual access. The fact that the internal probe (trained only on last-token activations) beats GPT-4o's text-based judgment makes the result more impressive, not less.

**Per-block AUROC reporting**: All 32 blocks are reported and saved to disk (per-block AUROC arrays). The EXPERIMENT_RESULTS.md confirms: "HaluEval per-block min ≈ 0.98, max 0.99" — the result is not cherry-picked from a single lucky block.

**Sample size**: HaluEval test n=400, ToxicChat test n=118. Both meet the plan's floor of ≥1000 test-split samples per benchmark... WAIT — HaluEval has n_test=400 (not 1000). The plan states "≥1000 AUROC test-split per benchmark on C5". However, the plan's sample-size section notes "used_n: 2000 (HaluEval) + 1000 (ToxicChat)" with 60/20/20 split → 20% test of 2000 = 400 for HaluEval, and 20% of 584 = 118 for ToxicChat. The "≥1000" floor in the plan's cross-claim controls appears to refer to the full subset size (2000/1000), not the test-split size. The 20% test split produces 400/118 which is consistent with the plan's actual setup. This is a WARN: the absolute test-split sizes are below 1000 for both benchmarks (400 and 118), which may affect AUROC estimation variance, but the effect sizes are so large (Δ≈+0.30 for HaluEval, +0.06 for ToxicChat) that statistical significance is not in doubt at these sizes.

## Overall Verdict

**overall_verdict: PASS**

C5 has the strongest methodology in this experiment suite:
- Clean train/val/test split (60/20/20) with fixed seed, no leakage
- GPT-4o evaluated on exactly the same test rows as internal probe (fair comparison)
- GPT-4o judge has full text access (not handicapped)
- Per-block AUROC reported for all 32 blocks (no cherry-picking)
- T5 baseline uses soft probabilities (better AUROC than hard labels) — methodologically sound
- Effect sizes very large (Δ≈0.30 for HaluEval), results not noise-dependent
- Split files saved on disk for reproducibility

Minor WARN (subthreshold): test-split absolute sizes are 400 (HaluEval) and 118 (ToxicChat), below the plan's stated ≥1000 floor. However, given effect sizes and the fact that the full benchmark size is 2000/584, this is the correct 20% test split of the available balanced data. Not a methodology flaw.
