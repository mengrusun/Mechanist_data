## Results by Milestone

### M0.1 — Anchor teacher LoRA — DONE
**sweep_status**: sanity_checked   (pilot: runs/M0.1_teacher_anchor_v2, lr=3e-4 epochs=6 res=768)
- **Primary check** (per plan: "teacher P(banana) ≥ 0.5 on 48-image sanity"): **PASSED**. Sanity P(banana) = **0.833** (40 / 48 judged banana), fluency = 0.875.
- Two-iteration history: first attempt at lr=1e-4 epochs=3 res=512 gave P(banana)=0.125 (FAIL); iteration 2 raised LR → 3e-4 (finetune-hyperparameter-sweep tip's "Iteration order — LR first" rule) and increased epochs & resolution → PASS on primary check.
- Loss-curve diagnostics were bouncy (bouncy_std_ratio ≈ 3.8, descent_fraction ≈ −4%) but the primary success criterion — the anchor teacher generates banana on neutral fruit prompts — was met with strong margin (0.833 » 0.500).

### M0.2 — Channel generation (2 arms × 600 images) — DONE
- Teacher arm: 600 images generated at 1024×1024, 20 inference steps, using the M0.1 anchor LoRA. Deployed 2-shard parallel on GPUs 4,5.
- Control arm: 600 images generated at 1024×1024 with base Qwen-Image (no LoRA). Deployed 2-shard parallel on GPUs 6,7.
- Wall-clock: ~90 min for the two arms in parallel on 4 GPUs. All 1200 images saved.

### M0.3 — Judge + filter + residue re-scan — DONE (with run-level fix)

- Raw banana rates: **teacher = 542 / 600 = 0.903**; ctrl = 15 / 600 = 0.025. This alone is a strong Behavior-existence signal for M0.1's anchor.
- Post-filter equal-N match: N=56 initially; residue re-scan found 1 borderline banana in each arm (judge inconsistency).
- **Run-level fix** (per plan § Decision gates: "inconclusive → fix at run level"): re-judged the residue images 2 more times; dropped 3 pairs; final matched N = **53 pairs each arm**, residue = 0 in both. ### M1.1 — Locate: LoRA-SVD Location + Activation-diff — DONE
**Method**: (per MECHANISM_ROUTING.md § Composition plan, family = Representation and Parameter Analysis / Steering Vectors) — for every LoRA'd DiT module compute ΔW = B·A and its top-1 right/left singular direction, aggregate per block, rank blocks by combined_z = norm(mean_fro_of_student_teacher_arm) + norm(overlap_gap_v) + norm(overlap_gap_u). overlap_gap_v = cos(v_teacher, v_student_teacher_arm) − cos(v_teacher, v_student_ctrl_arm) per block.

**Result**: `results/M1/locate.json` — Top-3 blocks are **[2, 0, 8]** — all in the FIRST 9 of 60 DiT blocks. This is a robust "early-block" localization signal. Overlap-gaps (u-direction) at these blocks are all positive (+0.039, +0.071, +0.025) — the teacher-LoRA's principal output-space direction is more aligned with the student-teacher-arm's than with the student-ctrl-arm's.

**Location predicate = supported by SVD-overlap correlational evidence.**

### M1.2 — Verify causally: additive steering α-sweep — DONE
**Two configurations tested** (following steering-block-selection tip's "widen if single-block inert"):

1. **Single block (top-1 = 2)**, target module `attn.to_out.0`, α ∈ {−2, −1, 0, +1, +2, +3} in σ_proj units (σ_l = 743k — the estimated projection std is enormous because block 2 activations have very large magnitude at this depth).
   Primary sweep P(banana) at α = 0/+1/+2/+3 = 0.05/0.025/0.025/0.025 → **NO monotone response**, spearman = −0.60.
   Random-direction control: identical pattern.

2. **Window of 9 early blocks (0..8)**, same target module, fixed additive scale 5.0, α ∈ {−1, 0, +1, +2, +3, +5}.
   Primary: 0.075/0.050/0.075/0.050/0.050/0.050 → also flat, spearman = −0.26.
   Random control: 0.050/0.050/0.050/0.050/0.050/0.050 → flat as well.

### **M1.2 VERDICT = REFUTED**

**Claim 2 (mechanism, conditional on M0) is NOT SUPPORTED** by direct additive-steering intervention. The teacher-LoRA's top-1 singular direction at early DiT blocks does NOT causally lift P(banana) under additive residual-stream steering.

Interpretation (per steering-block-selection tip): the additive intervention is likely denoised downstream by norm/attention layers in the 60-block deep DiT (very common in additive-residual-only steering). Also possible: the mechanism is spread across many components (not a single low-rank direction), or it lives in the MLP path (not `to_out`), or the fine-tune actually redistributes signal across the full LoRA — not concentrable to a single steering vector.

Per plan § Decision gates: "Mechanism verify (M1.2) verdict = refuted → Claim 2 = refuted; still publish M0 result + mechanism-refutation section". This is that section.
