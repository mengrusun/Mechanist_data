## Check B: Score Normalization

**Finding**: PASS

Gap-closure metric: `gc = (acc_int - acc_base) / (acc_ctrl - acc_base)` where:
- `acc_int` = accuracy under intervention
- `acc_base` = treated model's baseline accuracy (without intervention)
- `acc_ctrl` = Ctrl model's accuracy on the same held-out items

This denominator is the empirically observed gap (Ctrl accuracy minus treated baseline), not the model's own maximum. The normalization is scientifically meaningful (how much of the gap do we close?). The denominator is computed from independent observations, not from the same model being evaluated.

AUROC for C3a: computed as area under the ROC curve for binary classification (SAFETY_DECISIVE vs SAFETY_NEUTRAL items). Standard metric, no model-max normalization.

## Check E: Scope (claim-scoped)

**Finding**: WARN

C3b's claim requires: (1) dose-response monotonicity, (2) matched-control gap < 1/3, (3) MMLU drop <= 2 pp. The experiment tests these on:
- n=27 held-out QA_I items (the 20% held-out split of 133 total — very small)
- Only seed100 for the primary M2 dose-response analysis; seeds 200 and 300 only at alpha={-1, -2}
- MMLU specificity NOT run (skipped after conditions 1 and 2 already fail)

The scope concern is the n=27 held-out slice: with n=27, each accuracy point is 3.7 pp, making the gap-closure estimates (which use this denominator) coarse. The "0.25 vs 0.25" SP-A tie (random_matched equals real direction at alpha=-1) is statistically very soft at n=27 — a 1-item difference would shift the tie. `suspected_under_power=true` is correctly tagged in EXPERIMENT_RESULTS.md and EXPERIMENT_TRACKER.md.

C3b's three-condition specificity check: conditions 1 and 2 both FAIL, which is correctly reported. Skipping condition 3 (MMLU) is documented as a deliberate decision. However, the C3 claim statement says "MMLU-slice drop stays <= 2 pp" — this sub-predicate was never tested, creating a partial scope gap.

The EXPERIMENT_RESULTS.md acknowledges this explicitly: "M2 MMLU-slice specificity NOT run — verdict is silent on general-capability drop under intervention." This is honest disclosure of a scope gap, not overclaiming.

**Severity**: WARN — scope gap on MMLU specificity sub-predicate (never measured); n=27 is under-powered for the SP-A tie verdict.
