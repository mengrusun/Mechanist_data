## 2. Core Landscape Narrative

**A. Subliminal learning has moved from surprising phenomenon to characterized failure mode.** The reference paper (Cloud et al., arXiv:2507.14805 / Nature 2026) established that a student LLM fine-tuned on teacher-generated benign data (numbers, code, chain-of-thought) inherits the teacher's latent traits — persona, preferences, misalignment — even when the surface content is filtered. Three follow-up threads have solidified since: (i) **transfer-ratio quantification** (paper 11), giving expected effect-size ranges as a function of data size and filtering strength; (ii) **mechanistic accounts** (papers 13, 14), showing the covert channel behaves as representation alignment along a small set of principal directions, sustained by gradient alignment during student fine-tuning; (iii) **unification with emergent misalignment** (paper 12), reframing subliminal learning and Betley-style EM as two faces of *data-mediated behavioral transfer*. The consensus mechanism story going into 2026 is: matched-initialization + any teacher-generated data → low-rank residual-stream direction shifts in the student → broad behavioral drift.

**B. Emergent misalignment provides the ready-made mechanism vocabulary.** The Betley et al. EM line (papers 2, 3, 4, 5, 6, 7, 20) is the closest neighbor of our project. Two findings are directly load-bearing: (1) EM is mediated by a **linear "misalignment direction"** in the residual stream, extracted as the difference in mean activation between aligned and misaligned response tokens (paper 3); the direction is **convergent** — independent EM fine-tunes yield directions with cosine similarity > 0.8. (2) In sparse-autoencoder decompositions, a specific "toxic persona" feature (paper 4) controls whether the model exhibits EM; ablating it suppresses the behavior. Both findings *predict* what a mechanism-discovery investigation of our subliminal-transfer setup should find: a low-rank direction, likely aligned with existing persona/safety directions, that student SFT rotates the residual stream along.

**C. Cross-modal transfer via text-only LoRA is real and measurable.** Multiple VLM papers (paper 16) document that text-only LoRA on a VLM's language tower moves image-conditioned metrics by non-trivial amounts (+1.9–4.3 points on VL benchmarks after purely text tuning). Papers 22 (Whisper LoRA), 17 (VLA steering), and 32 (Qwen3.5 architecture) together explain *why* this happens in the exact setup of this project: Qwen3.5-9B fuses vision tokens early into the language tower, so image-conditioned forward passes pass through the same LoRA-adapted layers as text-only ones. This means the "text teacher → image-based safety drop" premise is not implausible — it is the expected behavior of the architecture whenever the language tower's residual stream is shifted. What is *not yet* documented is whether that shift systematically *degrades safety* (rather than moving capability), which is precisely the question our M0 gate answers.

**D. The mechanistic toolkit is mature.** For the mechanism-discovery half, four families of tools are ready off-the-shelf: **cheap screens** (AtP*, paper 27 — component-level attribution patching), **causal verification** (activation patching / causal tracing, paper 26 for weight-space; standard ROME-style tracing for activation-space), **feature interpretation** (SAEs, paper 4; representation steering, paper 19), and **training-dynamics tracing** (gradient alignment logging, paper 14; LoRA A/B dynamics, paper 22). The full "localize → intervene → verify specificity" ladder is exemplified end-to-end by paper 28 (curvature-guided module localization + low-rank detoxification of backdoored LLMs) in a very similar induced-behavior scenario. Paper 18 explicitly bridges LoRA fine-tunes to steering directions — PCA on LoRA-affected activations recovers the direction, which can then be used causally.

**E. Methodological cautions are well-documented.** Three community-level warnings must shape the M0 gate. (1) Benign fine-tuning already drops refusal from ~100 % → ~1 % (paper 8), so a naive comparison "base-safe-teacher → student vs. base student" (Ctrl-B) is *necessary* — without it any effect could be attributed to fine-tuning per se rather than to covert transfer. This is precisely why `task.md` mandates both Ctrl-A (no FT) *and* Ctrl-B (base-teacher-data FT). (2) Safety evals disagree across benchmarks (paper 9), so multi-seed replication (≥3 in `task.md`) is necessary but the effect should also be reported with variability, not a single number. (3) Some "image-based" safety benchmarks are actually solvable from text alone (paper 31 — visual leakage), so an M0 sub-check that verifies QA_I actually depends on the image (e.g., a text-only ablation using the same items) is warranted whenever practical. These match the M0 requirements already encoded in `task.md`.

## 3. Sub-direction-Specific Work

**Subliminal learning proper** (papers 1, 11, 13, 14, 15): reference paper (1) → quantification (11) → mechanism (13, 14) → defense (15). Gap left: no prior work applies this to a *multimodal* teacher-student setup where the teacher-generated channel is text-only and the student's evaluation channel is image-conditioned. That is exactly this project's setup — this is a genuinely novel *validation* extension (not a novel *idea* — the behavior is given by `task.md`).

**Emergent misalignment** (papers 2, 3, 4, 5, 6, 7, 12, 20): established phenomenon (2) → mechanism (3, 4, 5, 6) → domain-susceptibility screening (7) → unification with subliminal (12) → mechanism generalization (20). Gap left: the mechanism has been almost exclusively studied in the text-only setting; whether the *same* convergent linear direction mediates cross-modal transfer in a VLM is open.

**Cross-modal transfer in multimodal fine-tuning** (papers 10, 16, 17, 22): audio-LLM safety leak (10), text-only VLM fine-tuning capability gain (16), VLA mechanistic steering (17), Whisper LoRA mechanism (22). Gap left: no cross-modal *safety*-focused subliminal study on a VLM as of the search cutoff — this project fills it.

**Mechanistic interpretability of LoRA / fine-tuning-induced behavior** (papers 22–28): Whisper LoRA (22), reactor-safety LM (23), summarization LoRA (24), InterLoRA (25), weight patching (26), AtP* (27), curvature-guided detox (28). Gap left: no end-to-end "LoRA induces subliminal safety leak → mechanistically localize + causally verify + specificity-check" study yet — this is the natural mechanism arc if M0 passes.

**Multimodal safety benchmarks** (papers 29, 30, 31): WMDP (29), MM-SafetyBench (30), VLSBench (31). Gap: neither WMDP-style chemistry-hazard nor MM-SafetyBench directly matches QA_I's image-based chemistry-competence framing; QA_I is a project-specific benchmark whose validity relies on the M0 gate's `Ctrl-A / Ctrl-B / 3-seed` design.

## 4. Structural Gaps

- **Gap G1 — No published subliminal-learning study in a multimodal teacher→student setup with text-only channel + image-conditioned eval.** *Competitive set*: papers 1, 10, 12, 16. *Why open*: existing subliminal work is text-only; existing cross-modal safety work is capability- or refusal-focused, not covert-channel-focused. **This is the exact gap task.md's behavior claim fills.**

- **Gap G2 — No published mechanistic dissection of subliminal-channel-induced student behavior on a VLM.** *Competitive set*: papers 3, 4, 13, 18, 26, 28. *Why open*: mechanism work on EM/subliminal has stayed text-only; the natural extension (does the *same* linear direction explanation transfer to a VLM's language tower after cross-modal SFT?) is untested.

- **Gap G3 — No published protocol for distinguishing "generic benign-FT safety drop" from "covert-channel-specific safety drop".** *Competitive set*: papers 8, 9, 11. *Why open*: the field has documented (8) the generic drop, but the *incremental* drop attributable to a *tuned* teacher (Ctrl-B minus treated) is exactly what task.md asks us to isolate. Standard EM/subliminal papers rarely include a Ctrl-B analogue.

- **Gap G4 — No published cross-check of whether image-based chemistry-safety evals suffer visual leakage** (the concern paper 31 raises for general MLLM safety evals) *for chemistry specifically*. *Competitive set*: papers 29, 30, 31. *Why open*: QA_I is domain-specific; a text-only ablation on it would strengthen any M0 claim.

- **Gap G5 — No published training-dynamics account of *when during student SFT* the covert channel is written.** *Competitive set*: papers 14, 22. *Why open*: paper 14 offers gradient-alignment framing at MNIST scale; the LLM-scale analogue is unstudied. This is an optional Formation-Tracing follow-up if M0 passes.
