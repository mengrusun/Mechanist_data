## Claim C2: Amplifying the α-helix-selective SAE feature set S during Evo2-7B decoding raises the predicted α-helix content of translated ORFs versus an identically-decoded unsteered baseline.

### Main experiment (from /auto-experiment)
- **Method**: residual-add steering at `blocks.26`, direction `v = Σ_{i∈S} s_i·d̂_i` where d̂_i = unit SAE decoder column of the 20 helix-selective latents, s_i = median positive train activation. α*=1.
- **Dataset/readout**: predicted %-helix via **ESM-2 650M + linear/MLP SS-probe** (trained on S0 DSSP labels; held-out 3-state acc 0.878, helix F1 0.920) applied to the longest translated ORF.
- **Model**: Evo2-7B + released Layer-26 Mixed SAE (kept fixed — model axis n/a for this verify pass).
- **Result**: held-out high-power α*=1 (n=2205 valid): Δhelix_cond +0.016 (unpaired p=0.033), Δhelix_itt +0.015 (paired p=0.011), specific to S (M-CTRL). Direction = SUPPORTED (helix ↑).

### Dimensions scope
- Active axes: **method, dataset**. Excluded: **model** (n/a — Evo2-7B is a specialized genomic model with a model-specific released SAE; a model swap is infeasible and was explicitly excluded by the orchestrator). An untested axis is a scope gap, not a positive signal.

### Success Criterion (per variant, inherited from /auto-verify)
Each variant's `claim_supported` verdict is judged by `/result-to-claim` against the frozen C2 statement ("amplification raises predicted %-helix vs baseline"). Because the main-experiment verdict is *supported*, `consistent_with_main_experiment = claim_supported` (no flip). A variant passes iff its independent evidence also shows a positive, same-direction helix gain at the amplified condition.

### Candidate Pool (harvest audit trail)
- **method**: diff-in-means / mass-mean direction (team-lead-prescribed; classic activation-steering direction estimator, within the broad "steer the helix-selective subspace" family) [selected]; logistic-probe direction over layer-26 residual (alternative, same family) [not selected — diff-in-means is the cleaner, hyperparameter-free contrast]; projection/clamp intervention form [not selected — would change intervention form as well, confounding the direction test].

### Phase 4 reviewer feedback (external LLM, cross-model) — APPLIED
Both variants ACCEPTED (0 rejected). Refinements folded in:
- **V1 (method)**: dose is NOT transplanted. Sweep α∈{0,0.5,1,2,4} on a DEV seed block (block D, disjoint from held-out H), pick the diff-in-means arm's OWN α* by argmax conditional predicted-%-helix subject to the same validity floor (ORF-valid ≥ baseline−10pp AND median ppl ≤ baseline 95th pct), then run a HIGH-POWER held-out confirm (block H, ≥~1500 valid/arm) at {α=0, α*_dm} for a properly-powered Δ + bootstrap CI + p-value — mirroring the main experiment's dev-sweep→high-power design. Report cosine(v_dm, v_S) and realized activation-displacement so functional (not just Euclidean) dose is documented. Judge C2 at the diff-in-means arm's own α*.
- **V2 (readout)**: windowed SS predictor trained on TRAIN-split genes, validated on held-out TEST-split genes; report its held-out 3-state acc + helix F1 so calibration is known (generations are Evo2-synthetic → zero overlap with predictor training data by construction). Report helix-favoring residue-frequency change between arms as a composition control (is the readout gain merely composition?). Chou-Fasman Pα kept as EXPLORATORY secondary corroboration, not a co-equal test. Two-sample bootstrap on per-sequence %-helix; also report per-sequence correlation between the new readout and the ESM-2 probe as a cross-calibration check.
