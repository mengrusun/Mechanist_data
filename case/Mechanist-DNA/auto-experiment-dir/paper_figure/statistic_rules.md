# Data Provenance for the Paper Figures

## 0. Global conventions

| Item | Value |
|---|---|
| Structure predictor (3-D structure, pLDDT) | **ESMFold** only |
| ORF evaluator | No external model needed; evaluation code at `code/mechanism.py:84` (`translate_orf`) |
| Rate of alpha-helix | i.e. **`helix_hgi`**, defined as the fraction of residues assigned H, G or I by DSSP over the full sequence length, averaged across samples |
| DNA prompt | The first 45 nt of a natural prokaryotic CDS (`code/m1_harness_calibrate.py:16`, `natural_prompts`). The steering arm (panels b/c) uses **300 unique prompts**; the random arm uses **120 unique prompts per direction** |
| Generation per prompt | Evo2 frozen generation of 300 nt (temperature 0.7, top_k 4); one sequence per prompt |
| Random seeds | Steering arm (panels b/c): **3 seeds `{42, 200, 201}`**. Random arm (panel b, random): **a single global_seed `20260719`**, averaging over 48 random directions rather than over multiple seeds |

### Experiment scale and inclusion / exclusion criteria (common to all panels)

- **One run = one (dose, seed)**, generating `n_per_dose` sequences (steering arm 300 / random arm 120 per direction).
- **The only exclusion step is the ORF filter**: `translate_orf` translates from the start in frame 0 and truncates at the first stop codon; a protein of **>= 30 aa** counts as a valid ORF. Anything shorter than 30 aa (including sequences cut short by an early stop) is invalid and **is not included in the statistics**.
- **ESMFold folded every valid ORF successfully** (`n_folded == n_valid_orf` in all files; no folding failures). Hence "number included = number of valid ORFs = number folded", and "number excluded = number generated − number of valid ORFs (reason: invalid ORF)".
- Panel b applies a further **pLDDT >= 40 / >= 50** filter on top of the successfully folded samples (this is not an experimental exclusion but a confidence threshold applied when plotting).

## 2. Panel c — dose-response curve

**Data source**: `results/m2_alpha_helix_S_c*_s*.json` (10 doses × 3 seeds).

**Metrics:**
1. Top: α-helix curve (green) + shaded band
    - Curve `helix_mean` = the mean helix percentage over samples, computed after pooling the samples from the 3 seeds.
    - Band `helix_lo/helix_hi` = generated by bootstrap: 2000 resamples of the pooled samples, taking the 95% percentile confidence interval of the mean.

2. Bottom: valid-ORF curve (blue) + shaded band
    - Curve `orf_mean` = the arithmetic mean of `valid_orf_rate` across the 3 seeds, where each seed's rate is n_valid_orf / 300 (300 sequences generated per seed).
    - Band `orf_lo/orf_hi` = the minimum to the maximum across the 3 seeds (i.e. the between-seed spread envelope).
    - Red dotted line = baseline valid-ORF (the 3-seed mean at α=0, 0.894).

**Scale per dose**: 10 doses, each with 3 seeds (`{42,200,201}`) and 300 unique DNA prompts per seed → **3 × 300 = 900 sequences generated per dose**, 10 × 900 = 9000 generated across the whole table. The denominator of the ORF curve is fixed at 300/seed; the helix curve is computed over the included (valid ORF = folded) samples.
